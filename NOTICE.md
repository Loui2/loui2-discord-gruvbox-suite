# Attribution Notice

**Loui2 Discord Gruvbox Suite** contains modified Tampermonkey, BetterDiscord, and Revenge Android adaptations of [Gruvbox Sharp](https://github.com/round-panda/gruvbox-sharp), originally created by [round-panda](https://github.com/round-panda).

The desktop theme base was derived from Gruvbox Sharp version 3.2 as embedded in the Tampermonkey source used for this project. The upstream Gruvbox Sharp project continues to evolve independently.

The underlying Gruvbox color palette originates from [morhetz/gruvbox](https://github.com/morhetz/gruvbox).
